
# Retail Store Sales - Exploratory Data Analysis

## Project Overview
This project focuses on Exploratory Data Analysis (EDA)
of a Retail Store Sales dataset using Python.

## Dataset Information
- Total Records: 12,575
- Total Columns: 11
- File Format: CSV

## Tools & Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Data Cleaning
- Missing value identification and treatment
- Duplicate record detection and removal
- Data type conversion
- Handling categorical and numerical columns

## Exploratory Data Analysis

### 1. Univariate Analysis
- Histograms
- Box plots
- Frequency distributions

### 2. Bivariate Analysis
- Scatter plots
- Box plots
- Categorical comparisons

### 3. Multivariate Analysis
- Correlation heatmap
- Violin plots
- Monthly sales trends
- Multiple-variable visualizations

## Project Objective
To understand retail sales patterns, customer purchasing
behavior, payment preferences, and product category performance.

## Conclusion
This project uses data analysis and visualization to
identify sales patterns and generate useful business insights.
